# 🧮 Калькулятор на Python (PyQt5 + ОПН)

Графический калькулятор на PyQt5 с математическим движком, который вычисляет выражения через **Обратную польскую нотацию (ОПН)**. 

---

## ⚙️ Возможности приложения

* 🧠 **Расчет через ОПН:** Самостоятельная реализация алгоритма Сортировочной станции (Shunting-yard) на базе стека.
* 🛡️ **Проверка ограничений:** Обработка ошибок ОДЗ (деление на ноль, отрицательные аргументы логарифмов, выход за границы \([-1, 1]\) для арксинуса и арккосинуса).
* 💾 **Пользовательские переменные:** Возможность сохранять свои переменные и подставлять их в формулы. Защита от перезаписи чисел и встроенных функций.
* 🎯 **Точность вычислений:** Округление результатов тригонометрии и логарифмов до 12 знаков после запятой для компенсации погрешностей `float`.
* 🎬 **Анимированный интерфейс:** Плавное раскрытие панели дополнительных функций с автоматическим изменением высоты окна.

---

## 📊 Поддерживаемые функции и константы

* ➕ **Базовые операции:** `+`, `-`, `*`, `/`, `^` (или `**`), унарный корень `√`, факториал `!`.
* 📐 **Тригонометрия:** `sin`, `cos`, `tg`, `ctg` (аргументы в градусах), а также `arcSin`, `arcCos`, `arcTg`, `arcCtg` (результат в градусах).
* 📈 **Логарифмы:** натуральный `ln`, десятичный `lg`, произвольный `log(x, base)`.
* 🪙 **Константы:** e, π (доступна как `π` или `p`), золотое сечение φ (`φ` или `f`), ускорение свободного падения g.
