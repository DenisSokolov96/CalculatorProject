# 🧮 Калькулятор на Python (PyQt6 + ОПН)

Графический калькулятор на PyQt6 с математическим движком, который вычисляет выражения через **Обратную польскую нотацию (ОПН)**. 

---

## ⚙️ Возможности приложения

* 🧠 **Расчет через ОПН:** Самостоятельная реализация алгоритма Сортировочной станции (Shunting-yard) на базе стека.
* 🛡️ **Проверка ограничений:** Обработка ошибок ОДЗ (деление на ноль, отрицательные аргументы логарифмов, выход за границы \([-1, 1]\) для арксинуса и арккосинуса).
* 💾 **Пользовательские переменные:** Возможность сохранять свои переменные и подставлять их в формулы. Защита от перезаписи чисел и встроенных функций.
* 🎯 **Точность вычислений:** Округление результатов тригонометрии и логарифмов до 12 знаков после запятой для компенсации погрешностей `float`.
* 🎬 **Анимированный интерфейс:** Плавное раскрытие нижней панели дополнительных функций, а также выдвижная боковая панель для специализированных расчетов с автоматическим изменением геометрии окна.
* 📈 **Мастер формул:** Вынесенный в отдельный боковой блок модуль для мгновенного вычисления сложных математических и статистических моделей.
* 📈 **Многооконная визуализация (Matplotlib):
  * ** Построение полноценных интерактивных графиков математических функций в отдельных независимых окнах. 
  * ** Поддержка масштабирования (зум колесиком мыши/выделением), перемещения по осям и сохранения графиков в файлы (PNG/PDF).

## 📊 Поддерживаемые функции и константы

* ➕ **Базовые операции:** `+`, `-`, `*`, `/`, `^` (или `**`), унарный корень `√`, факториал `!`.
* 📐 **Тригонометрия:** `sin`, `cos`, `tg`, `ctg` (аргументы в градусах), а также `arcSin`, `arcCos`, `arcTg`, `arcCtg` (результат в градусах).
* 📈 **Логарифмы:** натуральный `ln`, десятичный `lg`, произвольный `log(x, base)`.
* 🪙 **Константы:** e, π (доступна как `π` или `p`), золотое сечение φ (`φ` или `f`), ускорение свободного падения g.
* 🧮 **Специализированные формулы (Боковая панель):**
  * **Формула Бернулли:** Расчет вероятности ровно $k$ успехов в $n$ независимых испытаниях.
  * **Арифметическая прогрессия:** Нахождение $n$-го члена ($a_n$) или суммы первых $n$ членов ($S_n$).
  * **Геометрическая прогрессия:** Нахождение $n$-го члена ($b_n$) или суммы первых $n$ членов ($S_n$).
* 📊 **Параметры графиков (Боковая панель):**
  * **Custom Range:** Динамическое управление границами отображения по оси X (Минимум X / Максимум X).
  * **Автоматический шаг:** Умный расчет шага генерации точек функции для обеспечения идеально плавной синусоиды без лагов.
  * **Защита от зависаний:** Ограничение максимального количества точек в памяти для защиты системы от перегрузки при экстремально маленьком шаге.
  * **Многооконность:** Возможность открывать и сравнивать бесконечно много независимых графиков одновременно с автоматической очисткой закрытых окон из ОЗУ.

## 🚀 Как скачать и запустить калькулятор (Без установки Python)

Вы можете запустить приложение на своем компьютере, не устанавливая Python и сторонние библиотеки. Все зависимости и ресурсы уже собраны внутри автономных пакетов.

1. Перейдите в раздел [**Releases**](https://github.com) в правой части этой страницы.
2. В блоке **Assets** скачайте исполняемый файл для вашей операционной системы:
   * На **Windows**: `Calculator-Windows.zip`
   * На **Linux**: `Calculator-Linux.AppImage`

### 💻 Инструкция по запуску:

* **Для Windows:** Распакуйте скачанный архив `Calculator-Windows.zip`. Кликните дважды по извлеченному файлу `Calculator.exe` (в него автоматически вшита фирменная иконка). При первом запуске фильтр SmartScreen может показать предупреждение. Нажмите **«Подробнее»**, а затем — **«Выполнить в любом случае»**.
* **Для Linux:** Вам не нужно ничего распаковывать. Скачанный файл `Calculator-Linux.AppImage` — это готовая программа «всё в одном». 
  1. Нажмите по файлу правой кнопкой мыши → **Свойства** (Properties) → вкладка **Права** (Permissions).
  2. Поставьте галочку **«Разрешить выполнение как программы»** (Is Executable) или просто выполните в терминале команду `chmod +x Calculator-Linux.AppImage`.
  3. Дважды кликните по файлу — калькулятор мгновенно запустится со своей родной зеленой иконкой прямо в вашем файловом менеджере!
